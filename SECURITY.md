# Security Policy

## Scope

This repository is a Red Team simulation project intended for authorized and isolated laboratory environments.

## Reporting a Vulnerability

If you discover a security vulnerability in the project itself, please do not publish exploit details immediately.

Prefer reporting privately through the repository's available GitHub security/contact mechanism.

Include:

- Affected file or component
- Reproduction steps
- Security impact
- Suggested mitigation
- Relevant logs or screenshots with secrets removed

## Important

Do not test this project against systems that you do not own or have explicit authorization to test.

## Sensitive Information

Never include the following in an issue or report:

- Passwords
- API keys
- Access tokens
- Private keys
- Session cookies
- Personal data
- Real target information

Use a disposable isolated lab when reproducing security issues.
